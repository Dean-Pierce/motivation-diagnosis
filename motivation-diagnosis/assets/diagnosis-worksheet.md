# 动机自检工作表（Motivation Self-Diagnosis Worksheet）

> 用法：把下面每一项填实，逐格推导出「卡在哪、为什么、下一步做什么」。
> 对应 skill：motivation-diagnosis（卢比孔模型 / 期望-价值 / 调节焦点等）。

---

## 1. 框定个案
- **对象**：□ 自己  □ 他人（谁：__________）
- **具体目标 / 任务**：________________________________________________
- **观察到的断点现象**（打勾）：
  □ 不想定（没动力想这事）
  □ 定不下（想要什么不清楚 / 多个目标打架）
  □ 动不了（决定了却启动不了）
  □ 撑不住（开始后又放弃 / 受挫）

---

## 2. 期望—价值（行为 = 期望 × 价值；任一项=0 → 不行动）
| 维度 | 自评（高/中/低） | 一句话证据 |
|------|----------------|-----------|
| 自我效能感（我能做到吗） | □高 □中 □低 | |
| 结果预期（做了有用吗）   | □高 □中 □低 | |
| 价值（好处>成本吗）       | □高 □中 □低 | |

→ 哪一项为 0？这就是首要干预点。

---

## 3. 目标冲突（勒温四类型，可多选）
□ 双趋（两个都想要，只能选一）
□ 双避（两个都不想，必须选一）
□ 趋避（同一目标又爱又怕）
□ 多重趋避（多个目标各有利弊）
→ 是否需要「目标屏蔽」保护焦点目标？________________________________

---

## 4. 调节焦点
□ 发展取向（"我想做成 X"，求收益、关注数量）
□ 维护取向（"我必须别搞砸 X"，避损失、关注质量）
→ 沟通 / 框架应顺应该取向（调节性匹配）。

---

## 5. 行动 / 状态导向
□ 行动导向（说干就干、能坚持）
□ 状态导向（动不起来、想太多、易复发）
→ 触发状态导向的常是：失败恐惧 / 外在压力。对策：执行意向 + 自主选择。

---

## 6. 心智模式（失败后第一反应）
□ 实体论（"我不行"）
□ 递增论（"再试试 / 换法子"）
→ 实体论者：用「大脑可塑 / 能力靠练」材料干预。

---
