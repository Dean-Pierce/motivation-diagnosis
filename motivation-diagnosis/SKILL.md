# 动机诊断与干预（Motivation Diagnosis & Intervention）

## 概述
本 skill 是一套「诊断 → 定位卡点 → 给干预」的可执行流程。
核心判断：**动机问题不是「懒」，而是某个具体机制在某一个阶段断了**。先定位断点，
再对症干预，而不是空喊「打起精神」。

## 何时使用
触发信号（用户原话或意图命中即启用）：
- 自我动机：「我没动力写报告 / 总是拖延 / 定了目标坚持不下来 / 一遇到困难就放弃」。
- 管理/教练视角：「团队不出单 / 怎么激励兼职销售 / 下属没干劲 / 孩子不爱学习」。
- 目标设计：「这个目标我总启动不了 / 同时想做好几件事互相打架」。

不要用于：纯情绪障碍（抑郁/焦虑需专业帮助）、与动机无关的任务规划（交给通用规划）。

## 诊断总流程（Rubicon 四阶段为骨架）
始终按以下顺序推进，每步只取必要信息，避免一次性盘问。

### 第 0 步 · 框定个案
确认三要素：(1) 对象（自己 / 他人）；(2) 具体目标或任务（越具体越好，模糊则先帮其具体化）；
(3) 观察到的「断点现象」——是**不想定**、**定不下**、**动不了**、还是**撑不住**？
现象直接映射到阶段（下一步）。

### 第 1 步 · 定位卡点阶段（卢比孔模型）
- **决策前 / 目标选择**：无法决定要什么、目标不切实际、或目标间互相冲突 →
  查「目标冲突」与「期望—价值」缺口，用审慎心态（开放、现实）理清。
- **决策 / 承诺**：决定了却没真正投入 → 用**心理对照**（幻想目标 + 认清障碍）提升承诺。
- **行动 / 规划**：承诺了却不动 → 用**执行意向**（如果…那么…）+ 目标具体化 + 行动心态（闭锁、乐观）。
- **行动后 / 评估**：做了却受挫、想放弃 → 处理自我效能归因、视情况**目标解除**。

详见 `references/rubicon-stages.md`。

### 第 2 步 · 并行跑杠杆检查
针对卡点阶段，逐一审视下列维度（哪个维度「为零/为负」就是主因）：
- **期望—价值**：自我效能感（我能做到吗？）× 结果预期（做了有用吗？）× 价值（好处>成本？）。
  任一项为 0 → 行为 = 0。见 `references/expectancy-value.md`。
- **目标冲突**：勒温四类（双趋 / 双避 / 趋避 / 多重趋避）？是否需要目标屏蔽？见 `references/goal-conflict.md`。
- **调节焦点**：发展取向（"我想…"、求收益、关注数量）vs 维护取向（"我必须…"、避损失、关注质量）？
  干预框架要与其匹配（调节性匹配）。见 `references/striving-control.md`。
- **行动/状态导向**：是否状态导向（难启动、易复发、被失败恐惧/外在压力触发）？见 `references/striving-control.md`。
- **心智模式**：失败后是否滑向实体论（"我不行"）？需推向递增论。见 `references/individual-differences.md`。
- **成就动机**：是害怕失败（回避、状态导向）还是希望成功（趋近、中等难度目标）？见 `references/individual-differences.md`。

### 第 3 步 · 输出干预
只给 **1–3 个最高杠杆**的具体动作，每条明确：用了哪个模型 + 可执行的一步。优先用：
- **执行意向模板**：「如果（情境暗示）… 那么（具体行为）」，并附后备计划（见 `references/commitment-planning.md`）。
- **心理对照（WOOP 式）**：写下愿望 → 结果 → 障碍 → 计划。
- **目标重写**：把「尽最大努力」改成「具体 + 有难度但可达」的目标。
- **框架匹配**：按对方调节焦点（发展/维护）调整沟通话术。
- **递增论干预**：用「大脑可塑/努力改变能力」的说服性材料替代「你真聪明」式表扬。

### 第 4 步 · 交付与自检
- 把诊断结论 + 干预清单交给用户；需要结构化自评时，给 `assets/diagnosis-worksheet.md`。
- 也可运行 `scripts/diagnose.py` 做一轮问答式结构化诊断（适合用户愿意逐步回答时）。

## 原则
- **先诊断后干预**，不凭直觉下结论；每个判断都能回溯到上面某个模型。
- **SKILL.md 只放流程**，细节下沉到 references/；模型定义以 references 为准，避免此处膨胀。
- 涉及真实心理困扰时，提示用户寻求专业帮助，本 skill 不替代心理咨询。
