# 奋斗与控制：调节焦点、行动/状态导向、目标解除

## 1. 调节焦点（Regulatory Focus）
同一目标可被两种导向驱动：
- **发展取向（promotion）**：把目标定义为「理想 / 我想…」，采用**急切策略**（抓机会、求进步、关注反应**数量**、强调**收益**）。
- **维护取向（prevention）**：把目标定义为「义务 / 我必须…」，采用**警惕策略**（避错、保稳定、关注反应**质量**、强调**避免损失**）。
- **调节性匹配（regulatory fit）**：当个体焦点与情境 / 任务框架「匹配」时，感觉"正确"、投入更多、表现更好（发展取向在强调收益的测试中更好，维护取向在强调避免损失的测试中更好）。
- 干预：沟通 / 设框架时**顺应**对方取向——对发展取向者讲收益与成长，对维护取向者讲稳妥与避损。

## 2. 行动导向 vs 状态导向（Action vs State Orientation）
- **行动导向**：能控制思想 / 情绪 / 行为以达成目标，更善启动并坚持；即使中断也能转向新活动。
- **状态导向**：难为新目标启动（易拖延）、难在适当时刻停止旧行为（易"旧瘾复发"）；被**失败恐惧或外在动机**情境触发，被**兴奋 / 自主 / 内在动机**情境激发为行动导向。
- 诊断：是否"动不起来、想太多、一有压力就卡住"？若是，按状态导向处理 → 用执行意向降低启动门槛、用自主选择（内在动机）对冲外在压力。

## 3. 自我控制（简要）
- 延迟满足、有限资源模型（意志力会耗竭）→ 避免自我控制失败：减少诱惑暴露、预设承诺、把行为自动化（执行意向 / 习惯）。
- 提高自我控制：把目标与情境暗示绑定、减少同时进行的自我控制消耗。

## 4. 目标解除（Goal Disengagement）
- 当目标已不现实或代价过高，继续坚持反受其害时，应**解除**目标。
- 促进解除：承认目标已不可行、把资源转向更有价值的目标、降低对原目标的情感投入。
- 注意：解除 ≠ 放弃所有目标；是战略性止损。
