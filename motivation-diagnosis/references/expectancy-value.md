# 期望—价值理论（Expectancy-Value）

## 核心公式
**行为 = 期望 × 价值**

- **期望（Expectancy）** = 自我效能感（感觉能执行）× 结果预期（行为会促成目标）× 乐观主义。
- **价值（Value）** = 实现目标的益处 > 追求目标的成本。
- 两者皆为**主观估计**，因人而异。乘法关系：**任一项为 0，行为即为 0**。
  - 期望 = 0（"我肯定过不了"）→ 即使价值很高也不行动。
  - 价值 = 0（"这对我没用"）→ 即使很容易也不行动。

## 诊断问句
1. **自我效能**：对完成这个**具体任务**，ta 自己觉得「能」吗？（注意：自我效能是**针对特定任务**的，不是整体自信。）
2. **结果预期**：ta 相信「做了就能推进目标 / 有好结果」吗？
3. **价值**：这件事的好处，是否明显大于付出的成本 / 痛苦？

## 干预
- **期望低（自我效能）**：给阶段性小胜、示范、陪练；用递增论重塑「能力可练」；拆解到「跳一跳够得着」。
- **结果预期低**：澄清路径与因果（做了为何有用），提供榜样 / 证据。
- **价值低**：重连目标与 ta 真正在意的东西（意义感、身份认同），而非单纯加外部奖励（避免挤出内在动机）。
- **目标太难 → 期望崩塌**：降到「有难度但可达」（参考成就动机的中等难度偏好，`individual-differences.md`）。
