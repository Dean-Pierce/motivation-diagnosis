# 卢比孔模型（Rubicon）四阶段与诊断

## 模型
动机过程被划分为四个阶段（Gollwitzer 扩展为两种心态）：

1. **决策前（Predecision）— 选择目标**。需要**审慎心态**：思想开放、现实、客观权衡利弊与自身能力。
2. **决策（Decision）— 对目标做出承诺**。
3. **行动（Action）— 执行**。需要**行动心态**：思想闭锁、对所选目标过度乐观、屏蔽其他选项。
4. **行动后（Post-action）— 评估结果**，调整或解除。

两种心态不能错位：决策前用行动心态（过早乐观）会选错目标；行动中用审慎心态（继续权衡）会偏离行动、难以坚持。

## 各阶段典型卡点与干预指针
- **决策前卡住**（定不下要什么 / 目标不现实 / 目标冲突）
  → 用审慎心态理清；查 `goal-conflict.md`；用期望—价值核对目标是否「期望×价值」过低（`expectancy-value.md`）。
- **决策/承诺卡住**（决定了却没真正投入）
  → `commitment-planning.md` 的**心理对照**：幻想目标 + 认清障碍，提升承诺（研究显示承诺度与成绩 +35%）。
- **行动/规划卡住**（承诺了却不动）
  → `commitment-planning.md` 的**执行意向**（如果…那么…）+ 目标具体化 + 切换到行动心态。
- **行动后卡住**（受挫、想放弃）
  → 处理自我效能归因（失败≠无能，看归因方式）；视情况参考 `striving-control.md` 的**目标解除**。
