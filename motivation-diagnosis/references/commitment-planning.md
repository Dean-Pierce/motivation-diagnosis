# 承诺与规划：心理对照、执行意向、目标设计

## 1. 心理对照（Mental Contrasting）——提升承诺
目标过程有三种心理策略：**沉溺于未来**（只幻想好结果）、**沉溺于现实**（只关注障碍）、**心理对照**（幻想目标 + 认清实现路上的障碍）。
- 研究显示**心理对照**对提升目标承诺度最佳（幻想实现理论）：进行心理对照的儿童，对良好表现的期望更高，测试成绩高出 **35%**；在数学、外语、人际关系等目标上承诺度均更高。
- 操作（WOOP 式）：写愿望 → 结果 → 障碍 → 计划（"如果…那么…"应对障碍）。

## 2. 执行意向（Implementation Intentions）——把意向变行动
- 定义：「如果（情境暗示 Y）… 那么（我就执行行为 X）」的"如果…那么"计划。
- 要具体到 **何时 / 哪里 / 如何 / 多长时间**，并备**后备计划**（"如果周一到周五没空，就周日晚上补"）。
- 与目标意向（"我打算多运动"）不同，执行意向说明了**起点与方式**。
- 证据：一项 94 项研究、8000+ 被试的荟萃分析，效应介于中到高；对**难启动的目标**尤其有效（如每月乳房检查：仅目标意向 53% 执行，写下时间地点后 100% 执行）。
- 形成方法：①确定促进目标的行为反应；②把它与某个情境暗示绑定（"看到电梯 → 走楼梯"），形成自动联结。

## 3. 目标具体性与难度
- **具体**目标（"为每款产品找至少 4 个理由"）比模糊目标（"尽最大努力"）带来更多规划与努力。
- **困难 + 具体**组合对绩效提升最大；但难度须「有挑战、不超出实际能力」（目标太脱离能力 → 期望崩塌 → 失败）。
- 缩短期限可提高速度，但要量力而行。

## 4. 规划中的常见偏差（提示用户）
- **规划谬误**：低估所需时间，导致中途放弃 → 做保守时间预估、预留缓冲。
- **损失规避**：对损失的敏感大于对等收益 → 用「避免损失」框架沟通对维护取向者更有效（见 `striving-control.md`）。
