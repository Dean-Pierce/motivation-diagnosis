# 个体差异：成就动机、心智模式、毅力与乐观

## 1. 成就动机（希望成功 vs 害怕失败）
- 成就动机强的人：偏好**中等难度**目标（太易无挑战、太难超能力）；表现出**蔡格尼克效应**（对未完成的事更难忘，推动完成）；绩效与长期成就更高（强动机领导的企业增长率高 250%；16 岁成就动机可解释约 40% 的 23 岁学业成功）。
- **害怕失败**者倾向回避目标、易被触发为状态导向；**希望成功**者趋近、愿挑战。
- 干预：对害怕失败者，降低对"失败"的惩罚感、用递增论 + 小胜积累自我效能；对希望成功者，给中等难度 + 清晰反馈。

## 2. 心智模式：实体论 vs 递增论（Dweck）
- 约 **40% 实体论**（能力固定）、**40% 递增论**（能力可塑）、20% 不置可否。
- 来源：**表扬方式**是主因之一——"你真聪明"（实体论式）反而削弱动力；"你很努力 / 有策略"更促递增论。
- 干预：用**说服性文章**或**强调大脑持续变化**的干预项目，可把人推向递增论（有益结果：更抗挫、更愿挑战）。
- 诊断信号：失败后第一反应是"我不行"（实体论）还是"我再试试 / 换法子"（递增论）。

## 3. 毅力（Grit）与乐观
- 毅力：对长期目标的持续投入；与成就相关，但需与「该不该坚持」权衡（见目标解除）。
- 乐观：对"好结果会出现"的一般性信念，是期望的一环；但需结合现实（审慎心态用于决策前）。
